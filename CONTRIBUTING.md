# Regarding Copyright

Please don't report this repository directly to GitHub for copyright concerns if you can contact me first. Instead, submit an **issue** in this repository.

GitHub Issues are my preferred way of handling copyright concerns because direct communication is less intimidating and gives us a chance to resolve things informally.

**This is a preference, NOT a requirement.** I'm not prohibiting anyone from using formal legal procedures or submitting a formal copyright notice.

## Who can report copyright concerns?

### I'm not the copyright owner

You don't have to be the original copyright owner to report a concern.

Copyright owners may authorize representatives or agents to act on their behalf. If you're submitting a formal request, I may need information to verify that you're authorized to do so.

If you're simply reporting a concern without claiming to represent the copyright owner, you're still welcome to open an issue.

For example:
- You noticed that I forgot to credit an artist.
- You believe a file is being used without permission.
- You want to be claimed as ABSOLUTE SH@#&$POST.

Unverified reports won't automatically result in a takedown. Making a good-faith report won't get you punished.

However, deliberately impersonating a copyright owner or submitting knowingly false information is a different matter.

### I'm the copyright owner (or an authorized representative)

I want to collaborate and resolve things as smoothly as possible.

If possible, create an issue identifying the file(s) involved and explaining your concern.

I'll review the request and try to resolve it.

For ordinary game content, I'd appreciate a replacement suggestion alongside the request. Ideally, the replacement should serve a similar purpose or have a similar intent to the original audio.

A few things to keep in mind:

- Replacement suggestions are appreciated, but they're not a requirement for submitting a copyright concern.
- If no replacement is suggested, I may need additional time to find suitable replacement content.
- A replacement suggestion does not override a legitimate request to remove copyrighted material.
- For BONUS-level content, such as Vibepong or The Insane Quest For Orange Juice's CUSTOM section, no replacement is required. I'll prioritize removing the reported content as soon as I can.
- I won't pay for replacement files. I'm doing this for fun, not profit.

If the content hasn't been removed yet, feel free to yell at me. Politely. Or not. I'll probably deserve it.

## Missing credits

If I'm missing credit for something hosted here, please let me know as soon as possible!

You don't need to be the copyright owner to point out missing or incorrect credits.
