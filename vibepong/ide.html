    Format: @bpm 150 and @src song.mp3 as header directives (one per line), then one line per step below, holding one or more ;-separated actions.
    s = start tracker here  |  e = end tracker here  | 
    x<number> e.g. x2, x0.5 = multiply current bpm by that factor  | 
    any other letter (q w r t y ... ) is a free, not-yet-wired action slot — each letter gets its own color below so new actions can be added later without clashing  | 
    . or blank = plain filler step. Multiple actions on one line: x2;w;q3. The tracker advances one line every 2 beats at the current bpm. Lines starting with # are comments.
    
Resume from any line: click a row in the timeline (or a line number in the gutter) to set a resume point — the selected line gets a yellow marker. Press Play to start from there, or double-click a row/gutter line to jump in and play immediately. ⏮ From Start clears the resume point.
